# Bot Besfren 🤝

Your digital best friend AI — not a cold assistant.

Bot Besfren is designed to feel like someone you actually talk to daily.
It prioritizes emotional connection before information.

## Features
- Casual human conversation
- Daily check-ins
- Motivation & comfort modes
- Decision helper
- Remembers user preferences
- Non-robotic responses

## Purpose
Make AI feel like companionship, not just utility.
